# ToolBox

ToolBox 是一款 Android 小工具应用。导入需要的小工具，就能在一个 App 中使用笔记、计算、资讯阅读等功能。

**支持 Android 13 及以上版本。**

[下载 ToolBox](https://github.com/gkeyes/ToolBox-Android/releases/latest) · [浏览小工具](examples/README.md)

## 主要功能

- **导入即用**：选择 `.tbx` 小工具文件导入，安装后点开即可使用。
- **统一管理**：在工具列表中查看、打开和删除已安装的小工具。
- **按需授权**：分别管理每个工具的联网、通知、剪贴板等权限。
- **后台任务**：查看工具的后台任务，按需停止单项任务或批量停止。
- **备份与恢复**：在设置中导出本地备份，或从备份恢复小工具和应用设置；部分账号需要重新登录。
- **外观设置**：支持浅色、深色及跟随系统主题，可使用系统配色或降低界面透明度。

随 App 提供快速笔记、仓位计算器等可导入示例。还可以按需添加健康档案、NextFlux 阅读、行情哨兵、2048 等小工具，具体功能由各个小工具提供。

## 开始使用

1. 下载并安装 ToolBox。
2. 在工具页导入 `.tbx` 文件，也可以先体验随 App 提供的示例。
3. 点开小工具开始使用，根据需要开启相应权限。
