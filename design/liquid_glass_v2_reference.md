# Liquid Glass 第二稿实现基线

批准的交互原型标题为“ToolBox · Liquid Glass 交互原型”，快照 SHA-256 为
`a12f9e4ae9c688a4aabb94c70d7a0484e12d314d1f1d08856c6a2ddccb739c7c`。本文件固定进入原生实现的
视觉与行为差异；原型中的演示数据不进入产品。

## 视觉骨架

- 一级页面使用 34sp 大标题和右侧 48dp 圆形主操作。
- 搜索紧跟标题；“最近使用”采用紧凑横向入口；已安装工具使用单一分组列表和细分隔线。
- 底部导航为留出页面边缘的悬浮胶囊，选中项使用强调色，标签和图标保留明确语义。
- 页面画布与正文底板保持中性。系统取色只影响强调色、焦点与选中反馈。
- 玻璃只属于导航和局部悬浮操作。关闭玻璃后，排版、层级、间距和可操作性保持不变。

## 产品实现差异

- 首页“正在运行”继续逐项显示真实后台会话，并保留每项打开、确认停止和搜索时可见的行为。
- 运行页顶栏不采集 WebView；工具 HTML 不套用宿主主题。
- Android 返回和现有分层转场保持不变，不仿制原型中的浏览器边缘拖动。
- 两套主题共用业务页面、权限模型、`.tbx` 格式、JS API 和 Room schema。

## 材质限制

- 使用 Haze 1.7.3；每个可见原生页面一个采集状态，模糊半径 24dp。
- 页面被覆盖、进入或返回转场期间、降低透明度开启以及无硬件加速时使用实色替代。
- 不在列表行、正文、输入区、弹层正文或玻璃内部继续嵌套玻璃。
