# 首页与工具操作改版

设计目标：保持 ToolBox 的 Liquid Glass / Miuix 主题、三项主导航及原有管理能力，把首页的常用入口与工具管理操作分清层级。

[设计稿：浏览、深色、整理、工具操作、分组选择](home-states.png)。此图是同一个设计的五种状态，由图像生成工具生成；后续首页菜单调整以本文件与实现为准。设计稿不是应用运行证据。

## 首页

- 顺序为最近使用、收藏、分组，保留运行中工具入口。最近使用水平滚动，不限制项目数。
- 一级分区标题 18 sp / 24 sp 行高 / 半粗体，使用主文字色；分区相距 20 dp，标题与内容相距 8 dp。设置页面现有标题不受影响。
- 工具图标 52 dp，保持原始比例；名称 13 sp / 18 sp 行高，居中最多两行，按实际文字占高，不预留空白第二行。完整名称可由无障碍服务和操作面板读取。
- 最近使用、收藏与展开分组使用相同列宽、16 dp 横向内距和 12 dp 列间距。网格最小列宽 72 dp，随字体放大增加；网格行间距 12 dp，末行靠左，行高由本行实际名称决定。
- 单个组只用一个连续背景。收起只显示名称、数量与箭头；展开显示组内图标。组标题 16 sp 半粗体，数量 13 sp，头部至少 52 dp，组底 8 dp；卡片总高随内容变化。
- 分组允许独立同时展开，保持已有展开状态，新分组默认展开。收藏空态提供添加收藏；空分组提供添加工具。新建分组统一放在首页菜单，分组区标题旁不再单独放按钮。
- 尚未安装任何工具时只显示一个全局空态及安装操作；有工具后再显示收藏、分组的各自空态。
- 分组标题的按压反馈覆盖标题整行，按展开状态裁剪顶部或全部圆角；全部工具卡片的主点击反馈覆盖整张卡片，并沿外轮廓裁剪。“更多”保留独立点击及反馈，不触发打开工具。
- 一条垂直 LazyColumn，网格按行惰性组合；不为全部组成员预建视图，不嵌套垂直滚动。

## 浏览和整理

- 首页顶栏右上角只放“…”按钮，点击展开 Miuix 锚定菜单：导入工具、整理首页、新建分组。菜单适配主题与大字，点外侧或返回关闭；选择后先关闭菜单，再进入对应操作。
- 菜单内“整理首页”进入编辑态，右上角切换为“完成”，方便直接退出；退出后恢复“…”菜单。全部工具页面仍保留直接导入入口。
- 浏览时，工具点击打开、长按操作面板；整理时，点击操作面板、长按拖动，不自动打开工具。
- 收藏、分组和组内工具分别排序。拖动采用真实二维测量坐标；到达安全内容区域边缘时自动滚动，源图标离开可见行后拖动仍持续。
- 拖分组时临时收拢组体；释放或取消恢复持久展开状态，此过程不写入折叠设置。
- 整理时提供“前移 / 后移”无障碍自定义操作，浏览时仍能访问工具动作。所有互动目标至少 48 dp。
- 返回优先退出面板，再退出整理。切换标签退出整理；系统重建保留整理状态和编辑草稿。

## 面板

- 工具操作是真底部面板：图标、完整名称和关闭；两个快捷动作“收藏 / 已收藏”“加入分组”；分隔后的“管理工具”进入已有详情。
- 拖动条和标题共用一个头部，普通标题约 64 dp；关闭仍为 48 dp 点击区。下拖标题可关闭，上滑保留列表滚动，长标题不阻断后续操作。
- 两个快捷动作改为图标与文字横排，最小高度 56 dp；大字换行时两项等高增长。管理入口保留独立导航行。
- “加入分组”在同一个面板内切换页面，搜索、多选复选框、即时保存；返回回到工具动作。空态提供新建分组，不堆叠多个弹层。
- 分组编辑包含名称、搜索、成员选择、取消 / 保存。保留已选成员顺序，新选择追加；仅保存本次草稿。
- 保存进行时锁定当前表单，保留关闭能力；仅匹配该次提交成功才关闭，失败保留草稿。即时操作按各自控件显示保存状态和错误，不阻塞无关操作。
- 收藏和分组归属保存时，在原图标或复选框位置显示忙碌反馈，控件高度保持稳定；当前操作禁用，其他操作可用。
- 删除组独立为危险操作并确认，仅移除组关系。失效工具/组对应面板及时关闭。
- 宽度自适应、深色和降低透明度遵循现有主题；面板包含系统安全区和键盘处理，背景不能误触。

## 宿主页面密度

- Liquid Glass 底部导航底板 58 dp，外部上下间距各 6 dp；系统安全区单独消费，选项点击范围保持至少 48 dp。
- 全部工具短条目至少 64 dp，省去重复的“已安装”；有用途说明的条目保留说明。单行设置至少 56 dp，有副标题至少 64 dp，长文字自然增高。
- 信息行短标签按实际内容占宽，值使用剩余空间；窄屏和大字改为上下排列，完整值可换行。工具详情名使用独立 20–22 sp 标题，首页大标题不变。
- 二级页面统一有效的 720 dp 阅读宽度；启动和运行错误卡片最大 480 dp，短内容自然占高，长错误可滚动到重试。
- 后台单项操作在常规宽度下置于条目末端，窄屏或大字换行；组间距不重复叠加。导入、外观和关于页面合并重复层级。
- 备份空闲态显示概览，确认、进度和结果优先展示当前任务。恢复工具清单逐项惰性组合为连续分组，保留全部覆盖和风险说明。
- 帮助中的短代码可与复制按钮并排，长代码继续换行、选择和完整复制。浏览器菜单保留所有动作，浏览器主题跟随宿主。

## 数据与验证边界

- 保持布局版本、组 ID、备份格式、Room、TBX manifest 和 ToolBox JS API 不变，不新增数量配额或权限。
- 内部布局写入增加提交 ID 与 Writing / Succeeded / Failed 回执，独立匹配，防止陈旧回执关闭新编辑。
- 行为测试覆盖导航、菜单动作与取消、卡片主操作与更多互不串触发、模式差异、二维与边缘拖动、无障碍排序、分组独立性、面板、保存失败/重试、状态恢复、实际文字高度、图标对齐、键盘避让及宽屏/大字几何。
- Android 编译与测试由现有 GitHub Actions 执行。自动截图验证维持已移除状态；设计稿不作为截图 PASS，不操作手机。
- 本次不新建 GitHub Release。应用构建版本为 0.8.5（38）。

## 收尾精修

- 搜索框沿用所在主题的控制圆角；有输入时提供 48 dp 清空按钮，清空保留焦点，键盘搜索收起键盘并保留即时筛选结果。全部工具、分组和成员搜索共用此行为。
- 设置行的文字、图标、箭头和图标按钮统一使用 Miuix 禁用色。成功反馈图标使用成功底色对应的前景色，保持浅深色可读性。
- 分组展开箭头使用短促、可中断的旋转；整理长按真正进入拖动时反馈一次触感，遵循系统动画和触感设置。
- 热缓存图标直接进入首帧；同版本覆盖安装和卸载通知可见图标刷新，保留完整版本身份复查、异步解码和原有缓存容量。
- 主动取消安装使用中性结果，清理或提交处理完成后才显示。结果和错误使用礼貌播报，进度不逐个百分点重复播报；成功默认停留 3 秒，系统无障碍设置可延长。错误和待处理提示保留至用户处理。
- 后台关闭区分保存和停止两个阶段，失败提供对应重试。保存关闭后只重试未完成的停止操作；批量停止汇总失败并继续处理其他目标。权限清理失败时保持关闭并提供“重试清除”，重试绑定当时的完整工具版本和授权记录。
- 云端对最终签名 APK 另做冷启动冒烟，检查安装版本、首屏完成绘制、首页导航和启动崩溃/ANR，并将证据绑定 APK 摘要。这仅覆盖启动和初始首页；完整 Release 运行、人工视觉、真实 TalkBack 和 HyperOS 真机验收单独注明状态。

## 性能细节

- 搜索只过滤已排序目录；排序、最近使用和名称拼音按各自依赖更新。收藏、分组展开与搜索输入不重复排序，名称缓存随当前工具目录释放，不增加数量限制或输入延迟。
- 根界面只观察外观和首屏就绪状态；搜索、收藏、分组及后台操作反馈由对应页面观察，不触发无关根界面更新。
- 同工具、同预期版本的重叠图标请求共享一次加载；单个消费者取消不影响其他消费者，全部取消后终止工作。每个新批次继续复查完整安装身份，覆盖安装仍明确失效，不将合并请求扩展成长期版本缓存。
- 网络流预算检查和桥接发送复用编码文本与字节长度；完整响应直接编码有效缓冲，减少原始正文的整份复制。授权复查、资源预算、取消和释放时机保持不变，完整响应仍需占用与正文规模相关的内存。
- 云端 performance 验证范围只运行目录、图标、根状态、网络与共享 RPC 的相关测试；最终签名 APK 单独验证启动。合并后应用输入未变时复用已通过的定向结果，回执注明原提交、运行与验证范围，不将局部通过写成全量通过。
