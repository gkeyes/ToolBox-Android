## 设计系统与页面

背景 `#F6F8F7`，表面 `#FFFFFF`，正文 `#18332C`，次级文字 `#67766F`，主色
`#16846A`，薄荷底 `#E6F3EC`，超出参考范围 `#B34838`。深色主题使用同一语义映射。
系统中文无衬线字体；标题 26/30px、章节 18px、正文/控件 15px、辅助 12/13px；
数值使用等宽数字。间距 4/8/12/16/20/24/32px，表面圆角 20px，控件圆角 12px，
48px 最小点击区。禁用照片、渐变、重阴影、装饰动画和多层卡片。

图标：叶子/概览网格/文档/试管/扫描/趋势/用户/设置/加号/返回/删除，24px，
1.8px 圆头描边，`currentColor`；选中概览网格实心。SVG 图表提供文本替代与数据表。

一级页面为「概览、记录、趋势、我的」。概览固定顺序为品牌与副标题、记录统计、
新增/识别、最近记录、指标趋势；空状态用真实的 0 和导入/新增入口。历史列表按需加载；
趋势选择检验标本和单位，不混画。我的承载档案、备份、AI、整理、月度记录天数和主题。
编辑为独立表单视图，固定保存栏，48px 输入行；离开未保存内容先确认。
用户在实施中补充参考范围录入优化：默认分开填写下限/上限，提供单侧限值、定性、
原文四种模式。这是对 editor 参考图单一文本框的明确功能修订，必要时自然增加表单高度。
宽屏最大 960px，概览主内容两列；窄屏单列；200% 字体不限制页面或输入项高度。

## 数据和安全边界

- 保留增删改、逐项/批量编辑、四类检验、趋势、月度天数、档案、Excel、AI 提取/摘要/追溯/整理。
- 新增旧 JSON 导入、无密钥 JSON 备份；导入先预览，重复项跳过，不覆盖不同结果。
- ToolBox 普通存储存记录，secure storage 仅存 Gemini 密钥；密钥不进入导入、导出和日志。
- 静态依赖全部本地，Excel 按需在同源 Worker 中处理。原 Node 服务不运行、不打包。
- AI 使用原站 Gemini 官方域名，主动确认发送范围后才调用原生代理；无真实健康数据联网 QA。
- AI 只做资料整理，不给诊断或用药方案；所有输出作为文本显示，不执行返回的 HTML。
- 无法解释的数值/范围为「未判定」，参考比较不等于医学诊断。
- 当前宿主 1MiB bridge 与 2MiB KV 约束：文件最多 700KiB，档案最多 600KiB；提前提示，不截断。
- 同源模块、严格 CSP、无直接 fetch/XHR、无内联事件、无 ServiceWorker；不修改宿主。

## 实施与验证顺序

1. 模型与安全导入、分组持久化、失败不提交。
2. 移动页面、编辑/查询/图表、备份 Worker、显式同意的 AI。
3. 模型/存储/备份边界测试，真实浏览器新增、编辑、重开、筛选、导入与界面对照。
4. 可重复打包、完整性、资源/manifest 校验；真机导入、SAF、联网 AI 明确分开记录。
