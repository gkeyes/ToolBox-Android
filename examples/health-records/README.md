# 健康档案

独立离线健康记录小工具。当前安装包：[健康档案 1.0.11](../packages/health-records-v1.0.11.tbx)，需要支持原生流式网络和长响应的 ToolBox 0.6.1 及以上版本；版本及能力声明以 [manifest](web/manifest.json) 为准。在 ToolBox 工具页导入安装包即可，工具采用未签名、严格安全模式。

默认空白安装，不含个人档案、历史或演示记录、API 密钥和旧站服务器。记录、个人档案、趋势与备份无需联网；文件选择、保存及 AI 权限按需授予。请定期导出备份，升级或卸载前尤其如此；升级后若设置页提示密钥缺失，请为对应服务重新保存。

## 记录、趋势与备份

- 支持血常规、血生化、尿常规、尿生化，提供整份记录、单项和批量编辑，以及个人档案、月度记录天数和系统/浅色/深色主题。
- 参考范围默认分别填写下限和上限；单侧模式支持 `<`、`≤`、`>`、`≥`，定性模式支持阴性/阳性，复杂说明使用原文模式。范围提示仅比较当前报告填写的参考值，不作诊断；无法可靠比较时显示「未判定」，不猜测为正常，也不补写缺失数值或参考范围。
- 检验日期使用页内日历，支持 1900—2200 年。取消不改日期，确认后仍需保存记录；未识别出日期时须对照报告修正。
- 「选择指标」和概览指标数按名称与标本汇总，血样和尿样分开。单位不同或缺失不拆分同组入口；不同写法未经改名不会自动视为同名。
- 同名、同标本记录的原始数值在一张趋势图中展示，保留原单位、结果和参考范围，不自动换算、补齐单位、删除或合并记录。单位不一致时明确提示；仅在单位和各次参考范围一致时显示共用参考区间带。原始记录按日期完整列出，批量编辑仍需明确选择原单位分组。
- 趋势选择器在页面内展开，支持搜索、点选、方向键和 Escape。标题左侧内部返回按钮保留来源页面或报告上下文，编辑返回后继续保留该位置。
- 在「我的 → 数据管理」导入旧站 Excel，或从原 `health.zip` 解压出的 `health/user_data.json`。导入前显示新增/重复数量；默认追加、去重，不覆盖不同结果。
- 应用清理后的完整备份时，须明确勾选「修订相同 ID 的记录，并替换指标库与别名规则」。只修订 ID、日期和类型一致的记录，本机其他 ID 的报告保留；导入不会切换本机 AI 服务。
- Excel 支持 `.xlsx` 和旧 `.xls`，尊重工作簿的 1900/1904 日期系统，导出保留原文。XLSX 在解析前检查 ZIP 元数据、实际解压大小和 CRC，拒绝损坏、伪造大小、目录外条目、ZIP64 及分卷文件；不支持安全解压的 WebView 会提示更新 WebView 或改用 JSON。
- 保存使用分桶写入和原子头指针切换，失败不推进内存状态；过期编辑拒绝提交并保留输入。保存期间锁定相关控件；已关闭的识别、导入或编辑流程不得用晚到结果覆盖新草稿。导出固定所选年份、数据快照和文件名，改变范围后重新生成。

## 可选 AI

在「我的 → AI 设置」选择 MiniMax 或 Google Gemini。本工具的 MiniMax 图片识别仅允许 `MiniMax-M3`，M2.x 用于文字整理；Gemini 填写自己账号可用的模型名称。MiniMax 中国站请求固定发往 `api.minimax.cn`，Gemini 请求固定发往 `generativelanguage.googleapis.com`，均经 ToolBox 原生网络代理。

两家密钥分别保存在宿主安全存储，不回显、不写入日志、不随备份导出，也不自动迁移旧站密钥。切换服务清空尚未保存的密钥输入，已保存密钥彼此独立。每次发送前展示服务、模型、发送内容及费用提醒；失败不自动重试或改发另一家。关闭或取消流程不能撤回已经发送的数据。

AI 只辅助识别和资料整理，不提供诊断或用药建议。识别结果先进入可编辑草稿，须人工核对日期、标本、名称、数值、单位与参考范围后保存。输出按文本显示，不执行 HTML。固定填写模板、字段 schema 和解析规则见 [AI 格式说明](AI_FORMAT.md)：MiniMax 优先通过声明的格式函数参数提交结果，该函数不执行操作；正常返回的完整 JSON 也须符合相同模板。程序检查字段、类型、标识、重复键、未知目标和重复/循环写入，不以本地医学白名单代替人工判断。

名称对齐先使用已确认的本地别名，其余交给本次选择的同一服务。候选目录来自当前记录、指标库和已确认别名，被替代旧名不重新成为标准候选。自动匹配仅额外发送识别名称、标本、单位及同组完整候选，不再次发图，也不发送历史结果、日期、参考范围或病史；最多额外调用 4 次，超出预算的完整候选分组留待人工核对，不截断目录。

AI 只能选择本次候选 ID，不确定时保留原名待核对；草稿展示原名与标准名，可恢复原名或手工选择。有效建议和错误建议分开核对，区分无建议、建议全部被拦截和调用/格式失败，失败不丢失已识别草稿。匹配不改结果、单位或参考范围，不删除、合并项目；方法与数量/比例差异作为核对提示。「记住已确认的名称对应」默认不勾选，勾选后按来源标本与原单位保存，空单位单独记录；目标须为同标本的已有名称，不要求单位相同。别名与本次报告原子提交，不改历史记录，未确认建议不成为永久规则。

「最新资料摘要」发送各指标最近一次结果及个人档案；「历史变化整理」发送完整历史及个人档案；「指标名称整理」只发送名称、标本、单位及出现次数；「检验类型整理」只发送记录标识、当前类型、指标名称和单位。类型建议须引用本报告的 1—3 个项目 ID，界面并列显示原始项目与理由，由用户确认。

完整历史按原始项目名、标本和原单位分组，每批默认不超过 12 KiB，必要时增至最多 64 KiB，总计最多 12 次调用。保留原日期、结果、单位、参考范围和同日重复行，个人档案仅随首组发送。发送前展示确切组数、费用与全部数据；程序按顺序合成各组章节，不再调用 AI。中途失败可明确选择只重试未完成组；完整回复到齐前不能保存为完整历史，退出流程丢弃临时结果，超预算不静默截断。

单次请求与工具网络声明均为 15 分钟，服务主动报错或断开可能提前结束。MiniMax 流式请求提供实时思考、耗时和取消按钮；M3 流式请求的 `adaptive` 表示开启思考。推理仅临时显示前 24000 字符，截断时明确提示，不写入报告或备份。

## 容量与图片处理

下列限制由 [数据模型](web/model.mjs)、[文件处理](web/io.mjs)、[图片检查](web/image.mjs)、[AI 请求](web/ai.mjs)、[ZIP 预算](web/zip-budget.mjs) 和 manifest 分别约束；超限提示原因，不截断数据。

| 对象 | 当前上限 |
| --- | --- |
| 单次备份导入文件 | 700 KiB |
| 规范化档案 | 600 KiB，最多 2000 份记录 |
| 报告原图 | 5 MiB；最多 2400 万像素，任一边不超过 16000 像素 |
| 发送图片 | 700 KiB |
| 完整 AI 请求 / 文件保存请求 | 各 950 KiB，包含接口封装后的内容 |
| XLSX 实际解压输出 | 单项 8 MiB，总计 12 MiB |
| 桥消息声明 | 8 MiB；档案、图片和请求仍分别受上述较小限额约束 |
| AI 响应 | MiniMax 流式请求 4 MiB，其他请求 512 KiB |

图片仅接受静态 JPG、PNG、WebP，声明大小和实际读取大小均检查。通过本地尺寸与解码检查后，700 KiB 以内保留原编码；较大图片转 JPEG，最长边先限制为 3200 像素，依次尝试 0.92、0.86、0.78 质量，再按 0.8 缩小，最长边不低于 1280 像素，原图更小时不放大。仍无法压至上限时提示裁切。

原文件不修改，发送前预览实际图片及压缩前后大小。保留原编码的图片可能携带位置等元数据，请先移除不需要的附带信息并遮挡无关个人信息；确认框也会提醒。压缩和识别不保证小字、数值或多组参考范围准确，仍需对照原报告。

## 设计与实现约束

- 小工具使用原生 HTML/CSS/JavaScript 和 SVG 趋势图，独立于宿主 Compose 设计系统。静态依赖全部本地化，Excel 由同源 Worker 按需处理，历史列表分批显示，记录索引仅在数据提交后重建；旧站 Node 服务和 CDN 不进入运行包。
- 使用同源模块和严格 CSP，页面 `connect-src 'none'`；联网经宿主代理，不直接使用 fetch/XHR，不使用内联事件或 ServiceWorker。普通存储保存记录、档案和偏好，安全存储只保存所选服务的密钥。
- 一级导航保持「概览、记录、趋势、我的」。概览依次为品牌与副标题、记录统计、新增/识别、最近记录、指标趋势；空状态显示真实的 0 和导入/新增入口。「我的」承载档案、备份、AI、整理、月度天数和主题。
- 保留首屏文案「健康档案」「记录身体，了解变化」「我的健康记录」「份检验记录」「项指标」「最近记录」「新增记录」「识别报告」「查看全部」「指标趋势」「查看趋势」「最近一次」。正式数据状态使用「本地保存」，业务日期、数值和类型来自存储，不为对齐设计图伪造数据点。
- 浅色采用暖灰绿背景 `#F6F8F7`、白色表面、深绿正文 `#18332C`、次级文字 `#67766F`、主色 `#16846A`、薄荷底 `#E6F3EC` 和超出参考范围色 `#B34838`；深色主题保持对应语义。系统中文无衬线字体与等宽数字，标题、章节、正文和辅助文字分层；间距采用 4/8/12/16/20/24/32 px，表面圆角 20 px、控件圆角 12 px。避免装饰照片、渐变、重阴影、装饰动画和多层卡片。
- 操作图标统一使用 24 px、1.8 px 圆头描边的 `currentColor` SVG，选中概览网格实心。品牌图标由内置 Image Gen 生成，使用档案、叶片和脉搏线的绿/薄荷配色；保留的 [原图](design/icon-v1.0.3-original.png) 与 [安装包图标](web/icon-v1.0.3.png) 分别用于源素材和实际界面。
- 编辑使用独立表单与底部保存栏，离开未保存内容先确认。保持 48 px 最小触控区、可访问名称、焦点提示和键盘操作；SVG 图表提供文字替代与原始数据表。窄屏单列自然滚动，宽屏最大 960 px，概览主内容两列；字体放大至 200% 时不锁死页面或输入项高度，不为塞入首屏压缩控件。
- [概览参考](design/overview.png) 与 [录入参考](design/editor.png) 是生成的虚构数据设计稿，不进入 TBX，也不作为真实 UI 或验收证据。实际控件与用户数据优先，参考范围的四种录入模式可自然增加表单高度。

## 开发、打包与许可

在仓库根目录执行 `node examples/health-records/dev/preview.mjs` 可启动仅监听本机的临时预览。[开发桥](dev/bridge.js) 是测试适配器，禁用预览网络请求，不提供生产级安全存储，不进入 TBX。浏览器或合成适配器的结果不等于 Android WebView、原生文件选择/保存、安全存储、TalkBack 或真实 AI 验证；自动截图验收已移除，不列为通过项。

执行 `bash examples/health-records/package.sh` 仅打包 `web/`，排除测试、开发适配器、设计稿和文档。默认输出路径见 [打包脚本](package.sh)，也可将另一个 `.tbx` 输出路径作为第一个参数；输出已存在时拒绝覆盖。打包本身不包含安装、提交、推送或发布。

表格依赖为本地 SheetJS CE 0.20.3，使用 Apache-2.0 许可，见 [随包许可证](web/vendor/LICENSE.txt)。
