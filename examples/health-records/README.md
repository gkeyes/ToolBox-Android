# 健康档案 1.0.7

独立离线健康记录小工具，1.0.7 适用于 ToolBox 0.3.7 及以上版本，以获得完整的 5 分钟网络等待支持。

安装包：`output/health-records/health-records-v1.0.7.tbx`（仓库根目录下），versionCode 为 8。
在 ToolBox 的工具页导入该文件即可；这是未签名、严格安全模式的工具包。
安装包不含个人档案、历史记录、演示记录或 API 密钥，也不包含旧站服务器。

## 使用

- 参考范围默认分别填写下限和上限，无需输入横线。单侧模式支持 `<`、`≤`、`>`、`≥`；定性模式支持阴性/阳性；复杂参考说明可使用原文模式。
- 超出范围的提示仅比较当前报告填写的参考值，不作诊断。无法可靠比较时显示未判定，不猜测为正常。
- 在「我的 → 数据管理」导入旧站 Excel，或从原 `health.zip` 解压出的 `health/user_data.json`。导入前显示新增/重复数量；不同结果不会覆盖现有报告。
- 如需应用清理后的完整备份，明确勾选「修订相同 ID 的记录，并替换指标库与别名规则」。只修订 ID、日期和类型一致的记录；本机其他 ID 的报告保留。默认仍是追加/去重，不自动覆盖。
- 「选择指标」按项目名称与标本汇总，血样和尿样分开；单位不同或缺失不拆分同组入口。概览指标数也按名称与标本计算。不同写法未经改名不会自动视为同名。
- 同名、同标本记录的原始数值放在一张图表中，保留各条原单位、结果和参考范围，不自动换算、补齐单位或删除记录。单位不一致时明确提示，不能直接比较时应先核对原报告；不同单位不共用参考区间带。原始记录按日期完整列出，批量编辑仍需明确选择原单位分组。
- 趋势入口在页面内展开，支持搜索、点选、方向键与 Escape；不再需要按单位切换曲线。
- 「指标趋势」标题左侧提供内部返回按钮。从报告详情进入时回到原报告，从底部导航进入时回到此前页面；编辑返回趋势后仍保留这个返回位置，不退出宿主。
- 记录、个人档案、趋势与备份无需联网。需要使用时再授予文件选择/保存权限。
- AI 为可选功能：在「我的 → AI 设置」选择 MiniMax 或 Google Gemini。MiniMax 报告图片识别请选择 `MiniMax-M3`；M2.x 模型只能整理文字。Gemini 继续使用自己账号可用的模型名称。切换服务会清空尚未保存的密钥输入，已保存的两家密钥彼此独立，不互相使用。
- MiniMax 中国站只连接 `api.minimax.cn`，Gemini 只连接 `generativelanguage.googleapis.com`，均经 ToolBox 网络代理。每次发送前显示服务、模型、内容和费用提醒；失败不会自动改发另一家。密钥仅存于宿主安全存储，不自动迁移旧站密钥，也不导出到备份。导入档案不会切换本机正在使用的 AI 服务。
- 检验日期使用小工具内置日历，直接选择年、月、日，不依赖 Android 或桌面浏览器的系统日期弹层。支持 1900—2200 年；取消不改日期，确认后再保存记录。未识别出日期时仍需人工核对。
- AI 识别先进入可编辑表单；已确认别名先在本地匹配，其余名称自动交给本次选择的同一 AI 服务，与本地标准目录对齐。显示原名与标准名，可恢复原名或手工选择。未知、上下文不足或冲突的名称保留待核对，不改结果、单位、参考范围，不删除或合并项目。AI 内容按文字呈现，不作为 HTML 执行。
- 自动名称匹配只另发识别名称、标本、单位和同组候选，不再次发图、不发送历史结果、日期、参考范围或病史。发送确认包含目录和最多 4 次额外调用的费用提醒；完整候选分组超过预算时明确留待人工核对，不截断目录。名称匹配失败不丢失已识别草稿。
- 「记住已确认的名称对应」默认不勾选。明确勾选后按识别来源的标本与原单位保存对应，空单位也单独记录；目标须为标本、方法和数量性质兼容的已有名称，但不要求目标单位相同。与本次报告一起原子提交，不改历史记录；未确认的 AI 判断不成为永久规则。
- 默认空白安装。请定期导出备份，卸载工具前尤其如此。

## 本版优化

1.0.7 恢复原版按项目名＋标本归类的曲线逻辑，血样与尿样隔离，同组所有原始数值在同一张趋势图中展示，不因单位缺失或不同而机械排除。数值不做隐式换算，单位不一致时明确警示且不绘制共用参考区间带。原数据结构、历史内容及编辑防冲突不变。

新增趋势内部返回按钮，保留进入前的页面与报告上下文。修复 AI 网络超时、连接/读取失败及宿主内部失败落入笼统错误的问题；失败显示服务、模型、阶段、耗时和公开错误码，不显示原始错误正文或密钥。成功但 0 条建议使用独立完成提示，并说明检查范围，不再与失败混淆。

AI 单次请求与 manifest 均设为 300000 毫秒（5 分钟）；服务返回即显示结果，连接失败、服务主动报错或断开仍可能提前结束。MiniMax-M3 继续关闭思考模式，不自动重试或改发其他服务。宿主 0.3.7 修复只设置 callTimeout、读取/写入仍沿用 10 秒默认值的问题，改为使用请求与 manifest 中较短的时限；连接建立仍最多 10 秒。网络域名、重定向、私网阻断和配额均不变。该原生修复通过本地测试，手机实际行为与正式签名升级包另行验收。

修复名称对齐在缺失单位时直接跳过 AI、不同单位时筛空候选的问题。OCR 和「指标名称整理」都以同标本的确定同义名称为目标，单位只作辅助；不同方法、数量/比例冲突、未知候选、重复目标仍拒绝。恢复原版缩写/全称规则及 WBC、GPT、GLU 等例子，并补充 HbA1c、LH；旧版已确认别名在兼容标本下优先本地使用，被替代旧名不重新成为标准候选。草稿显示本地匹配数、AI 尝试次数、对齐数及未匹配原因，区分未调用、没有确定对应与失败。只改草稿名称，不改结果、单位、参考值或日期。

图像提示词恢复标本优先的血常规/血生化/尿常规/尿生化规则，保留原报告缩写与方法，由后续目录匹配统一名称；优先明确检验/采样日期，其次报告日期，不使用截图时间。类型整理需引用本记录实际指标作理由。未恢复旧版把阈值当普通数值、以其他记录参考范围补空白的处理。

1.0.6 修复识别草稿日期入口依赖系统控件的问题：日历图标由小工具绘制，手工新增、整份编辑与识别草稿统一使用页内日历。取消不修改草稿；闰年、月末和跨年使用有效日期，保存期间锁定，失败保留输入。桌面 1.0.5 原生日期输入点击文字区只获得焦点；用户手机缺少原生图标的行为未在 Android 真机复现，不能把桌面截图当作手机验证。

1.0.6 已将图片入口放宽到 5 MiB（5 × 1024 × 1024 字节），声明大小和实际读取大小都检查，并把工具消息额度提高到 8 MiB；1.0.7 保留这些限额，不改变备份/档案容量或 HTTP 请求大小上限。静态 JPG、PNG、WebP 在本机解码检查后，700 KiB 以内保留原编码；较大图片转 JPEG，最长边先限制为 3200 像素，依次尝试 0.92、0.86、0.78 质量，再按 0.8 缩小，最长边不低于 1280 像素（原图更小时不放大）。无法压到 700 KiB 内时提示裁切。原文件不修改，发送前预览实际图片及压缩前后大小，完整 AI 请求仍须通过 950 KiB 检查。

标准名称目录来自当前记录、指标库及已确认别名；被替代的旧名不重新成为标准候选。匹配时隔离血样/尿样、数量/比例及已注明的不同方法；1.0.7 不再仅因单位不同或缺失排除同义名称。AI 只能返回已有候选标识，经本地校验后填入草稿。关闭流程或开始其他编辑后，旧图像处理与匹配结果不得覆盖新草稿。此功能只辅助整理，不能代替人工核对医学含义。

1.0.5 修复 MiniMax 在原生 ToolBox 中返回 HTTP 400：ToolBox 的对象请求编码会将 `max_completion_tokens: 8192` 写成 `8192.0`，与接口要求的整数类型冲突。小工具改为在本地生成 JSON 文本再交给原有网络代理发送，保留整数字面量；Gemini 的整数输出上限也采用同一路径。域名、权限校验、密钥存储、网络代理和消息限额均不变。HTTP 400 提示不再直接归因为账号权限不足或重复要求切换到已经选择的 M3。

1.0.4 按 [MiniMax OpenAI 兼容接口文档](https://platform.minimaxi.com/docs/api-reference/text-openai-api) 接入 M3 图片/文字能力及 M2.x 文字能力。图片使用 base64 内容块，关闭 M3 thinking 并分离推理内容，只解析最终 JSON；识别结果仍需用户核对后保存。不加入未声明的 `response_format` 参数，不引入 SDK、远程脚本或自定义代理地址。

区分 HTTP 失败、余额不足、套餐额度、密钥权限、模型参数和截断输出；服务原始错误正文不会显示或记录。报告提示词要求缺失单位留空，不把水印或截图时间当报告日期，多组参考值完整保留，不擅自选取其中一组。设置页保存期间锁定服务、模型与密钥，防止写错服务或丢失新输入。

1.0.3 修复异常类型备份写入后无法打开、识别结果晚到覆盖新草稿、保存期间继续输入后丢失修改、大批量修订在预览前被默认追加限额挡住、旧重复指标改检验类型被误拦、趋势小数刻度和页内版本号。保存时整份/批量编辑控件暂时不可修改，失败后保留草稿；关闭 AI 弹窗会忽略此后返回的结果，但不能撤回已发送的数据。

Excel 导入尊重工作簿的 1900/1904 日期系统，导出保留包括嵌套 `_xHHHH_` 在内的原文；检查必需表头，拒绝 ZIP64、分卷及矛盾 ZIP 元数据。对精度不足或下溢的数字显示未判定，不自动重写原始结果。图标为新生成的绿色健康档案图案，工具列表、首页与页面图标共用 `web/icon-v1.0.3.png`；生成提示与原图放在 `design/`，不进入 TBX。

本版不修改私人数据或已交付 Excel。宿主仅按授权调整网络等待并同步 SDK 说明，不新增能力或联网地址。升级前先导出备份，使用同签名宿主更新，再更新 TBX；不要卸载旧工具。宿主更新工具时会清理安全存储，AI 密钥可能需按设置页提示重新保存。

1.0.2 支持将单字“阴”识别为阴性，兼容“阴性(-)”等既有写法；带滴度、范围或其他说明的文字仍不简化推断。参考原文模式可以保留并编辑“阴”。这不改变原有数值与范围计算，也不自动重写用户导入的档案；私人数据的文字统一另行交付。

1.0.1 修复依赖系统弹层的选择控件、旧重复项目阻止保存、趋势单项编辑后返回错误页面，以及 Excel 特殊文字导出失真。跨年趋势带年份，稀疏日期避免标签重叠；非负数据不会因坐标留白出现负数刻度。私人数据的清理与复核文件单独交付，不进入安装包。

使用轻量原生 HTML/CSS/JavaScript 和 SVG 趋势图，移除旧站 CDN、Chart.js、Tailwind 运行时与常驻 Node 服务器。表格库只在备份任务中由 Worker 按需加载，历史列表分批显示，记录索引只在数据提交后重建。支持系统/浅色/深色主题和窄屏布局。

持久化经 ToolBox API 完成，使用分桶写入和原子头指针切换；写入失败不推进内存状态。两家 AI 密钥分别使用宿主安全存储，不回显到表单、日志或导出文件。

当前安全限额：单次备份导入文件不超过 700 KiB，规范化档案不超过 600 KiB；报告原图不超过 5 MiB，发送图片不超过 700 KiB，完整 AI 请求不超过 950 KiB。文件保存仍受宿主消息大小和权限约束，超过时会提示原因，不截断数据。

报告图在 700 KiB 以内时通过本地解码检查后保留原文件，不再二次缩图或有损重编码，以保留小字和竖线旁的数字；超过时使用上述有界压缩。原图可能携带照片位置等元数据，发送前请移除不需要的附带信息并遮挡姓名等内容，确认框会提醒。AI 识别并不保证准确，结果和每组参考范围仍需核对。

表格库为 [SheetJS CE 0.20.3 官方发行版](https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js)，许可证在 `web/vendor/LICENSE.txt`。未新增远程脚本加载。
