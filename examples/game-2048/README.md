# 2048 ToolBox 小工具

一个完全离线、适合手机滑动操作的 2048。页面不联网，不加载远程字体或图片，也不使用任何
后台能力。

## 功能

- 手指滑动、鼠标拖动、方向键和 WASD 操作。
- 标准 4×4 合并规则、得分、最高分和步数。
- 一步撤销，新游戏前确认，达到 2048 后可继续挑战，棋盘无路可走时给出结束操作。
- 开启 ToolBox 存储权限时自动保存棋局和最高分；关闭后仍可完成当前会话。
- 开启 ToolBox 触觉权限时，触摸滑动和合并会给出轻触反馈。
- 浅色、深色、320 px 窄屏、横屏两栏、200% 字体、键盘焦点和减少动效适配。

## 包内容

```text
manifest.json
index.html
style.css
game.js
app.js
icon.svg
integrity.json  # 打包时生成
```

`game.js` 只负责可独立验证的棋盘规则，`app.js` 负责页面、输入、ToolBox 存储与触觉桥接。
清单仅声明 `storage` 和 `haptics`，两项都不是完成游戏的必需权限。

## 运行与打包

浏览器预览可直接打开 `index.html`。浏览器中没有 ToolBox API 时，游戏完整可玩，但不会跨刷新
保存棋局，也不会产生原生触觉反馈。

在本目录运行：

```sh
./package.sh
```

默认生成 `examples/packages/game-2048-v1.0.0.tbx`，已有文件不会覆盖；也可将新输出路径作为第一个参数传入。脚本生成完整性清单、固定 ZIP 时间戳，并检查包中没有
多余父目录或文件。

## 最小验证说明

### 1. 合并规则与得分

- 理由：2048 的核心是每次滑动中每个数字最多合并一次，错误的连锁合并会直接改变玩法。
- 方法：对四个方向覆盖 `2,2,2,2`、`2,2,4,0`、满棋盘可移动/不可移动，并用随机棋盘检查滑动前后数字总和不变。
- 预期：方向、合并目标和得分正确；核心函数不修改输入棋盘；没有非法数字或双重合并。

### 2. 真实页面交互

- 理由：按钮、滑动、键盘、撤销和结束层必须真实驱动同一棋盘状态，不能只有静态界面。
- 方法：在浏览器中完成新局、一次键盘移动、一次触摸滑动、撤销、重新开始确认，以及胜利/结束层操作。
- 预期：每次有效输入只移动一次；分数、步数和按钮状态同步；覆盖层不会让棋盘继续误操作。

### 3. 响应式与无障碍

- 理由：ToolBox 会在手机竖屏、横屏和放大字体下运行，棋盘和操作区不能重叠或越界。
- 方法：检查 320×640、390×844、844×390、深色、200% 字体、键盘焦点和减少动效。
- 预期：16 个格子保持等宽；横屏使用明确两栏或安全单列滚动；按钮命中区不小于 48 px；文字无裁切，焦点可见。

### 4. 权限降级与包结构

- 理由：存储和触觉是可选权限，关闭它们不能阻止游戏；`.tbx` 必须能被当前安装器原子检查。
- 方法：分别提供和拒绝 ToolBox API，完成一局操作；连续运行两次 `package.sh` 并比较 SHA-256、ZIP 条目和 `integrity.json`。
- 预期：无权限时仅失去跨会话保存/触觉；两次包字节一致，入口、图标和完整性哈希均有效。
