# 稳力 1.0.2

离线盆底训练小工具，包含准备、训练、完成和设置页面。它不联网，不提供诊断或治疗建议。

[下载可导入包](../packages/kegel-trainer-v1.0.2.tbx)。本版将最低 ToolBox 版本声明从误填的 1.0.0 修正为 0.6.4；原 1.0.1 文件保留。

## 功能与实际边界

- 入门、标准、耐力、快速和自定义训练节奏；支持开始、暂停、继续、提前结束、总结和再练一组。
- 基于截止时间计算倒计时，页面不可见时自动暂停，返回后手动继续。
- Web Audio 阶段提示音及四段包内中文语音；可选震动、屏幕常亮取决于 WebView 是否支持。
- 浏览器允许本地存储时保存偏好和最近 30 次完成记录；ToolBox 的无状态 WebView 中记录仅保留当前会话。
- 本工具尚未接入 ToolBox 的 storage/haptics 接口，因此未声明原生权限。ToolBox 本身已提供这些接口，后续适配需另行实现。
- 支持窄屏、横屏、键盘和减少动效模式。运行页面填满系统安全区域，ToolBox 不叠放返回按钮。

## 封装

运行 `./package.sh`，默认输出 `examples/packages/kegel-trainer-v1.0.2.tbx`；已有文件不会覆盖，也可传入新的输出路径。

安装包只包含清单、网页、脚本、样式、PNG 图标、四段离线语音和完整性清单。`icon.svg` 保留为可编辑图标来源，不放入运行包。包内没有训练记录、账号或网络密钥。

本次整理核对了文件和版本，并修正安装声明；未重新执行手机训练流程、语音、震动或屏幕常亮验证。
