# 无缝长图

离线拼接同一页面的连续截图，识别固定界面和重复正文，按原图像素裁切组合。无网络、OCR 或在线模型依赖。

## 安装与在线更新

- 发布文件：`seamless-stitch-v<版本>.tbx`，随 ToolBox 的现有 TBX CI 打包并发布到 `dev` 测试版；正式版沿用仓库发布流程。
- 保留首次交付的工具 ID：`io.gkeyes.seamlessstitch`。宿主更新订阅已增加对应映射，升级不会另外安装一个不同身份的工具。
- 在 ToolBox「设置 → 软件更新」选择测试版渠道，可查看自动发布到 `dev` 的新版本。先更新包含相册选择器和该工具身份映射的宿主，再更新小工具。
- 更新宿主后，“添加截图”会打开 Android 系统相册，一次最多选取 12 张。支持有序选择的系统会保留点击顺序。其他系统按选择器返回顺序导入，回到工具后可按编号核对并重排。较旧宿主仍可逐张添加。

## 功能

- 最多 12 张纵向截图，按编号从上到下拼接。可以拖动缩略图的手柄，也可以前移、后移或倒序。自动识别固定栏和重复内容，检测到反向重叠时提示检查顺序。
- 点击长图或接缝标记打开编辑器，以固定拼缝为基准，分别上下拖动上图、下图。支持鼠标、触摸和方向键，每次拖动可撤销（保留最近 20 次）。
- 拖动只改变所选一侧的裁切位置；限制在原图范围和相邻接缝之间，保持每张至少一行像素。中断手势会回滚本次调整。
- 预览顶部可直接保存。在“导出选项”选择格式和尺寸，在“调整接缝”定位每处接缝。重叠高度支持数字、滑块和 ±1 px 按钮，多图只编辑当前接缝。
- 裁切范围预览、上下左右边缘数值调整和完整长图预览。
- PNG 无损；JPG 95% / 85% / 65% 三档画质；原始宽度、75%、50%、限宽 1080 px。
- 低置信度、重复截图和无法匹配的接缝须检查或明确确认后才可导出。接缝提示线不会写入最终图片。
- 完整预览、接缝编辑和使用说明弹窗打开时锁住背景页，内部仍可滚动；关闭或系统取消时恢复原位置。完整预览固定标题与操作区，长图独立滚动。
- 只声明 `files.open` / `files.save`；图片留在会话内存中，退出前需导出。

## 识别方案与边界

先通过同坐标差分和分隔线定位固定栏，再通过分区行特征搜索滚动距离，最后验证像素与边缘误差。在重叠部分选择低纹理接缝，用 Canvas 组合原图；不重写文字、不补画缺失内容。

适用于同一缩放比例的连续滚动截图。宽度相差不超过 10% 时按较小宽度统一；页面重排、动态视频、正文上方的固定悬浮窗、缺少重叠等可能需要手动处理。任何截图都未包含的内容无法恢复。支持浏览器可解码的 PNG、JPG、WebP；照片选择器中的 HEIC 等格式会提示不支持。

输入单张不超过 40 MiB / 2400 万像素，总计不超过 6000 万像素。输出最多 3200 万像素、宽 16384 / 高 32760。PNG 无损指不再有损压缩；不能恢复 JPEG 原图已丢失的细节。缩小尺寸会重采样。

## 开发与验证

- `engine.js`：纯 JS 差分、匹配、接缝和组合计划。
- `worker.js`：后台匹配；旧宿主限制 Worker 时回退到同一算法。
- `runtime.js`：用 `files.openMultiple(limit)` 取得相册选择顺序，逐张读取单次 token。旧宿主用 `files.open(['image/*'])`，导出用 `files.save`。
- `app.js`、`index.html`、`style.css`：会话、裁切、排序、预览和画质导出。

在仓库根目录执行：

```sh
node --test examples/seamless-stitch/tests/*.test.cjs
python3 scripts/ci/tbx.py build --tool seamless-stitch
```

CI 注册于 `scripts/ci/tbx-targets.json`。测试和包内运行均不需要 npm 依赖，公开用例使用合成页面，覆盖固定栏、逆序、重复、多图接缝、原生图片选择顺序和取消、二进制导出及安装身份。

1.2.0 以 Chromium 实测鼠标和触摸拖动、手势取消回滚、撤销、方向键、数字与加减同步、单栏展开、PNG/JPG 画质与缩放，在 393 × 852、320 × 640、1100 × 900 及深色布局检查无横向溢出。用户样本经实际浏览器导出检查，结果为 864 × 1864 px，重复段落一次保留，固定界面已裁除；PNG/JPG 画质、50% 尺寸、手机和桌面布局通过 Chromium 测试。原生系统相册及实体 Android 安装流程需与宿主一起验证，接口模拟不等于真机测试。

更新时保持工具 ID，提高 `version` / `versionCode`，使用官方打包脚本生成新的完整性清单。不要提交用户截图或测试输出。第三方授权见 `THIRD_PARTY_NOTICES.md`。
